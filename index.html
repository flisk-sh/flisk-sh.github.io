Flisk CLI

Install Flisk CLI on Linux or macOS for the full local runtime. The latest release also includes a Windows AMD64 CLI for inspection; landscape startup on Windows uses Ubuntu in WSL2.

curl -fsSL https://flisk.sh/install.sh | sh

Windows AMD64: install from PowerShell with irm https://flisk.sh/install.ps1 | iex, then run flisk --version, flisk runtime --check-assets, and flisk doctor. Native Windows is for CLI inspection; use WSL2 Ubuntu for flisk project and flisk up.

Prefer npm? npm install -g flisk

Binaries are published at flisk-sh/releases.
