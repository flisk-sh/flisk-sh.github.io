About the numbers

A repo is active when it is public, not archived, not a fork and was pushed in the last 90 days. Each repo's last 100 workflow runs on its default branch are read; pull-request runs are left out.

Pass rate counts passed against failed and timed-out runs; cancelled and skipped runs are left out. A workflow is red when its newest completed run failed.
