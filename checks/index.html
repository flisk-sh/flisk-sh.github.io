Every number comes from the GitHub API or from scripts/scores/run.mjs in flisk-sh/flisk; nothing is estimated and no model is involved. A repo counts as active when it is public, not archived, not a fork, and was pushed in the last 90 days. A workflow is red when its newest completed run on the default branch failed or timed out. The pass rate counts successes against failures over each repo's last 100 default-branch runs; cancelled and skipped runs are left out. The snapshot refreshes hourly from collect.mjs.
